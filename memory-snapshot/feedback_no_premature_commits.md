---
name: Do not ask to commit prematurely
description: User wants to test thoroughly before committing — don't keep asking to commit/wrap up
type: feedback
---

Don't repeatedly ask "want me to commit?" or "want me to wrap up?" during active testing sessions. The user will say when they're ready to commit.

**Why:** User wants to test thoroughly and may have more changes/fixes before committing. Premature commit requests are annoying.

**How to apply:** Wait for the user to explicitly ask for a commit. Focus on fixing issues and updating docs instead.
